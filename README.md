# پروژه شبکه حمل‌ونقل شهری

این پروژه یک پیاده‌سازی خط فرمانی با جاوا ۱۷ از یک گراف وزن‌دار و بدون‌جهت برای شبکه حمل‌ونقل شهری است. ایستگاه‌ها به‌عنوان رأس‌های گراف و مسیرها به‌عنوان یال‌های وزن‌دار در نظر گرفته می‌شوند. فرمان‌ها از ورودی استاندارد خوانده می‌شوند و اجرای برنامه تا دریافت فرمان `EXIT` یا رسیدن به پایان فایل (EOF) ادامه دارد.


## ساختار پوشه‌ها

```text
src/
  Main.java
  algorithms/
  cli/
  graph/
  structures/
  tests/
  undo/
```

## فرمان‌های پشتیبانی‌شده

```text
ADD_STATION <station_name>
ADD_EDGE <first_station> <second_station> <weight>
BFS <first_station> <second_station>
SHORTEST_PATH <first_station> <second_station>
DEADENDS <starting_station>
MST
DIAMETER
SEARCH <prefix>
UNDO
EXIT
```

مثال:

```text
ADD_STATION Tajrish
ADD_STATION Mirdamad
ADD_EDGE Tajrish Mirdamad 5.5
BFS Tajrish Mirdamad
```

خروجی:

```text
Station added successfully
Station added successfully
Edge added between 'Tajrish' and 'Mirdamad' with weight 5.5
Tajrish -> Mirdamad Total Cost: 5.5
```

## ساختمان‌داده‌های سفارشی

در این پروژه، ساختارهای ذخیره‌سازی موردنیاز به‌صورت دستی پیاده‌سازی شده‌اند:

```text
DoublyLinkedList   فهرست‌های مجاورت
HashTable          نگاشت نام ایستگاه به شناسه ایستگاه
CustomQueue        صف پیمایش BFS
CustomStack        پشته برای DFS تکرارشونده و رکوردهای بازگردانی
MinHeap            صف اولویت دایکسترا همراه با decreaseKey
RedBlackTree       نگهداری مرتب نام ایستگاه‌ها و جست‌وجوی پیشوندی
DisjointSet        تشخیص چرخه در الگوریتم کروسکال
DynamicObjectArray ابزار کمکی ذخیره‌سازی در مرحله توسعه
```

کد از آرایه‌های اولیه، آرایه‌های اشیا، رشته‌ها، ورودی و خروجی استاندارد و ابزارهای عددی استفاده می‌کند. این پروژه به پیاده‌سازی‌های آماده مجموعه‌ها در جاوا یا کتابخانه‌های آماده گراف و الگوریتم وابسته نیست.

## الگوریتم‌ها

`BFS` مسیری با کمترین تعداد ایستگاه میانی را پیدا می‌کند و سپس مجموع وزن یال‌های مسیر انتخاب‌شده را محاسبه می‌کند.

`SHORTEST_PATH` از الگوریتم دایکسترا همراه با کمینه‌هیپ سفارشی و فهرست‌های مجاورت استفاده می‌کند.

`DEADENDS` از الگوریتم DFS تکرارشونده همراه با پشته سفارشی استفاده می‌کند. بن‌بست، ایستگاهی قابل‌دسترسی است که درجه آن دقیقاً برابر با یک باشد.

`MST` از الگوریتم کروسکال، مرتب‌سازی ادغامی سفارشی و ساختمان‌داده مجموعه‌های مجزا استفاده می‌کند.  
خطوط مربوط به مسیرهای انتخاب‌شده، وزن هر مسیر را نیز نمایش می‌دهند و با نمونه موجود در فایل PDF فارسی مطابقت دارند.

`DIAMETER` الگوریتم فلوید–وارشال را روی یک ماتریس فاصله اجرا می‌کند.

`SEARCH` ابتدا از تابع `lowerBound` در درخت قرمز–سیاه استفاده می‌کند و سپس با فراخوانی‌های پیاپی تابع جانشین، نتایج را به دست می‌آورد.

`UNDO` برای افزودن‌های موفق ایستگاه و یال، رکوردهای معکوس را ذخیره می‌کند تا عملیات قابل‌بازگردانی باشند.

## پیچیدگی زمانی

| عملیات | پیچیدگی مورد انتظار |
| --- | --- |
| `ADD_STATION` | جست‌وجوی مورد انتظار `O(1)` به‌همراه درج درخت با پیچیدگی `O(log N)` |
| `ADD_EDGE` | جست‌وجوی مورد انتظار `O(1)` برای ایستگاه‌ها، به‌همراه پیمایش فهرست مجاورت برای تشخیص یال تکراری |
| `BFS` | `O(V + E)` |
| `SHORTEST_PATH` | `O((V + E) log V)` |
| `DEADENDS` | `O(V + E)` |
| `MST` | `O(E log E)` |
| `DIAMETER` | `O(V^3)` |
| `SEARCH` | `O(log N + K)` |
| `UNDO` | برای بازگردانی یال، `O(1)` به‌همراه پیمایش حذف از فهرست مجاورت؛ برای حذف ایستگاه از درخت، `O(log N)` |

## فرضیات

نام هر ایستگاه باید تنها یک توکن بدون فاصله باشد و به بزرگی و کوچکی حروف حساس است.

گراف به‌صورت یک گراف ساده و بدون‌جهت در نظر گرفته می‌شود؛ بنابراین حلقه روی یک رأس و یال تکراری میان یک جفت ایستگاه پذیرفته نمی‌شود.

وزن‌های منفی، مقدار `NaN` و مقادیر بی‌نهایت رد می‌شوند؛ زیرا استفاده از الگوریتم دایکسترا الزامی است.

برای فرمان‌های `BFS A A` و `SHORTEST_PATH A A`، خروجی به‌شکل `A Total Cost: 0.0` خواهد بود.

اگر گراف همبند نباشد، فرمان `MST` عبارت `No MST Found` و فرمان `DIAMETER` عبارت `Graph Disconnected` را چاپ می‌کند.

قانون شکستن تساوی‌ها قطعی است: ترتیب درج در فهرست مجاورت برای BFS و DFS، شناسه ایستگاه برای تساوی‌های هیپ، ابتدا وزن یال و سپس شناسه دو سر یال و ترتیب ایجاد برای MST، و ترتیب الفبایی نام دو سر مسیر برای تساوی‌های قطر گراف در نظر گرفته می‌شود.

## آزمون

کلاس `tests.ProjectTestRunner` برای هر ساختمان‌داده سفارشی، آزمون‌های متمرکز و برای فرمان‌های افزودن ایستگاه و یال، مسیرها، جست‌وجو، MST، قطر گراف و بازگردانی عملیات، آزمون‌های یکپارچه اجرا می‌کند. این آزمون‌ها فقط از توابع ساده بررسی شرط استفاده می‌کنند و به هیچ چارچوب آزمون خارجی وابسته نیستند.

## پاک‌سازی منابع

فرمان `EXIT` و رسیدن به پایان فایل (EOF) هر دو مسیر پاک‌سازی یکسانی را اجرا می‌کنند. گراف در این مرحله فهرست‌های مجاورت ایستگاه‌ها، ارجاع‌های نمایه‌گذاری‌شده ایستگاه‌ها، فضای ذخیره‌سازی مسیرها، ساختارهای جست‌وجوی ایستگاه، گره‌های درخت جست‌وجوی پیشوندی و رکوردهای بازگردانی را پاک می‌کند.
